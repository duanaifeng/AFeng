# AI.FENG

沿世界线观测、学习、创造。保持好奇，让每一次编译都在世界线上留下一枚坐标。

## 作品

**资源导航站** — 把散落各处的工具、软件与影音收进同一张星图。`Vanilla JS` `2026.06`

**网络管家** — 局域网自己开口说话，设备探活成图，数据全在本地。自动拓扑图与三协议探活；网段、名称、IP、图标全自定义；宽带账号、路由后台、WiFi 密码按节点存档，纯本地存储、零上传，支持备份导出。`Vanilla JS` `2026.11`

**街道日历** — 四街循环推演成可携带的时间线，可导入手机日历。以 2026-02-15 为基准推演西邑、永信、羊邑、丙麻四街循环；赶集头晚 20:00 与当天 08:00 各提醒一次，默认订 3 年。`Vanilla JS` `2026.02`

**工时记账** — 临时与正式双线并行，把每一天折成工资。平时 1.5 倍、周末 2 倍、节假日 3 倍自动结算；节假日一键标记，补贴项自由添加，可选 GitHub 同步，数据默认只在本机。`Vanilla JS` `2026.10`

**怀旧游戏库** — 旧时光重新编译成可点的窗口。23 款游戏，5 大分类，零外部依赖。斗地主、保山幺子分、推箱子 100 关、超级马里奥；触屏与键盘双支持，点开即玩。`Vanilla JS` `2026.09`

**电脑维护工具** — 一切的开端。站长用易语言编写的装机辅助与故障排查小工具包，针对国内常见场景，打包即用。`易语言` `2025 早期`
