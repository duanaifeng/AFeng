## 📖 项目介绍

本项目是使用 **GitHub Pages** 部署的纯静态个人导航网站，**无后端、无广告、无需登录**。

面向数码爱好者，聚合网络工具、影音、系统装机、开源脚本等各类实用站点；同时内置**保山本地便民工具**与一套**怀旧网页小游戏**。
