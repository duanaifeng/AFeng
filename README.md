一、这是什么
----------------------------------------------------------------

AFeng 是我自己用的五个网页小站，全部是「单文件 HTML + 原生
JS」，没有构建流程、没有 npm、没有框架、没有 CDN 依赖，扔进
GitHub Pages 就能跑。

五个站共用同一套设计令牌（颜色 / 玻璃材质 / 圆角 / 阴影 /
页脚 / 回到顶部），所以从一个站跳到另一个站，视觉上不会有
「换了个网站」的感觉——这也是整个项目最花时间的部分。

二、五个站点
----------------------------------------------------------------

1. 导航站
   文件：index.html + data.json
   功能：10 大分类、60+ 精选站点收藏
   亮点：全局搜索、分类筛选、单条多入口弹窗、深浅色跟随系统

2. 个人主页
   文件：主页.html
   功能：站长名片与技术笔记入口
   亮点：唱片播放入口、技能栈、项目时间线

3. 怀旧游戏库
   文件：游戏.html
   功能：23 款浏览器直玩小游戏
   亮点：每款游戏专属配色、逐个手绘的可辨识图标

4. 工时记账本
   文件：工时.html
   功能：临时工 / 正式工双模式工资核算
   亮点：日结月结自动换算、月度统计、使用说明弹窗

5. 西邑赶集日历
   文件：赶集.html
   功能：本地四街集日循环查询
   亮点：三态语义色、导出 .ics 订阅手机日历

   部署地址统一为 https://duanaifeng.github.io/AFeng/
   各站按文件名直接访问，例如：
   .../AFeng/game/     .../AFeng/ganji/

三、设计语言：冷蓝液态玻璃
----------------------------------------------------------------

整个项目只允许一个色相家族（蓝），不出现第二组装饰色。
功能语义色（赶集的绿 / 黄 / 红、灯笼的鞭炮红金）单独保留，
因为它们承载信息，不是装饰。

[ 色彩令牌 ]

   --bg-1    浅 #f1f6fd   深 #04070d   页面底色
   --bg-3    浅 #dde7f4   深 #08111d   卡片底 / 分区
   --acc     浅 #2f6be0   深 #7cb0ff   主色、链接、进度环
   --acc-2   浅 #8ec5ff   深 #a9d3ff   次强调、悬停
   --ink     浅 #091524   深 #e8f0fb   主文本
   --ink-2   浅 #2f455b   深 #aec2d8   次级文本
   --ink-3   浅 #5c7288   深 #788da4   说明文字
   --ln      浅 rgba(24,52,98,.10)
             深 rgba(150,190,255,.11)  分割线、描边

   主渐变：linear-gradient(145deg,
           #2b62d6 0%, #3b7cf6 48%, #63a2ff 100%)

[ 玻璃材质三档 ]

   不是所有元素都开 backdrop-filter——长列表里那样做会掉帧。

   .surface    开模糊 blur(30px) saturate(185%)
               全站唯一的大面积毛玻璃：顶栏、侧栏、面板

   .overlay    开模糊
               弹窗遮罩与弹层

   .card       不开模糊，只靠填充 + 边缘高光
   .pill       同上
               列表项、按钮、标签，几百个也不卡

   发丝边框用 --g-edge（1px 内描边模拟玻璃边缘折射），
   阴影三级递进 --glass-sm / --glass / --glass-hi。

[ 统一交互件 ]

   · 页脚
     「Site Uptime / 本站已运行」年月日实时计数，
     加状态徽章（部署 / 版本 / 技术栈 / 框架 / 体验 /
     协议 / 隐私）与版权行。五站逐字一致。

   · 回到顶部
     胶囊按钮 + SVG 进度环（r=21，strokeDasharray=2πr），
     滚动时环随进度填充，箭头居中不偏移。

   · 图标基线
     所有内联 SVG 统一 fill:none; stroke:currentColor，
     尺寸由 CSS 单点管理，杜绝「默认黑填充」事故。

四、目录结构
----------------------------------------------------------------

   AFeng/
     index.html     导航站（主题基准，其他四站对齐此文件）
     data.json      导航数据：分类 / 图标 / 配色 / 条目 / 弹窗
     主页.html       个人主页
     游戏.html       怀旧游戏库（23 款）
     工时.html       工时记账本
     赶集.html       西邑赶集日历
     README.txt     本文件

   改动顺序约定：
   先改 index.html 的设计令牌，再同步到其余四站。
   这样主题永远只有一个源头，不会出现「三个站是浅蓝、
   两个站是深蓝」。

五、技术栈
----------------------------------------------------------------

   HTML5 · CSS3（自定义属性 / :has() / clamp() /
   容器查询）· 原生 ES6+
   0 框架   0 依赖   0 构建   0 外部字体   0 埋点

   · 数据驱动
     导航站的分类、条目、图标、配色全部来自 data.json，
     加一个新站只需要改 JSON，不碰 HTML。

   · 主题系统
     一个 data-theme 属性 + prefers-color-scheme 兜底，
     手切与系统跟随都支持，选择记在 localStorage。

   · 游戏实现
     Canvas 2D / DOM 网格两套渲染，键盘 + 触摸双输入，
     移动端虚拟方向键。无 WebGL、无第三方引擎。

   · 日历导出
     纯前端拼接 iCalendar（.ics），支持 1 / 3 / 6 / 10 年
     跨度，导入手机日历后形成订阅提醒。

   · 本地优先
     工时数据、主题偏好、查询历史全部存在浏览器本地，
     服务端零数据。

六、部署
----------------------------------------------------------------

仓库设置 → Pages → Source 选 Deploy from a branch，
分支 main、目录 / (root)，保存后等一分钟即可。

   git clone https://github.com/duanaifeng/AFeng.git
   cd AFeng
   直接双击 index.html 就能本地预览，不需要起服务

因为全部是相对路径 + 无跨域请求，本地 file:// 打开和线上
行为一致。data.json 部分浏览器会因 file:// 的 CORS 限制读
不到，这时用 python -m http.server 起一个静态服务即可。

八、已知限制
----------------------------------------------------------------

   · 纯静态
     没有后端，因此没有账号、云同步与跨设备数据。
     工时数据只在本机浏览器里。

   · 游戏兼容性
     老游戏逻辑基于键盘，移动端用虚拟按键映射，
     操作手感不如实体键位。

   · 第三方链接
     导航站收录的是外部站点，其可用性、内容与安全性由
     对方负责，与本站无关。
