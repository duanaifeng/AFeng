## 📖 关于这个仓库

这是我的个人作品合集，从 2025 年 7 月 28 日上线至今，一路折腾出来的五个小工具。

一开始只是想给自己做一个「电脑维护工具箱」的下载页，后来慢慢长成了现在的样子：**资源导航、赶集日历、怀旧游戏、工时记账**，还有你正在看的这个主页。

所有页面都是**纯手写**的 HTML + CSS + JavaScript，**零依赖、零框架、零构建**。打开就是源码，改一行就能生效，图的就是干净、稳定、看得懂。

> 保持好奇，用代码和工具拓展认知边界。

## ✨ 各项目简介

### 🏠 主页 · `/`
个人门面。展示头像、简介、作品卡片、每日金句、在读 / 在听、时间线动态、技能栈与联系方式。首页嵌了一个 **自动打字的终端动画**，纯 CSS + JS 实现，切到后台会暂停、回来会续播，不浪费电。

### 🧭 资源导航站 · `/daohang/`
把日常好用的工具、软件、影音入口收进一页。

- 分类 + 卡片布局，短描述一眼看懂
- **本地搜索**（Ctrl / ⌘ + K 唤起），支持拼音首字母模糊匹配
- 卡片详情弹窗，访问前自动检查 HTTPS 协议
- **编辑模式**：本地编辑，或配置 GitHub Token 后直连仓库同步
- 数据存 `daohang/data.json`，改文件即改站点

### 🏮 赶集日历 · `/ganji.html`
给西邑乡赶集用的实用工具。

- **四街循环**：西邑街 → 永信街 → 羊邑街 → 丙麻街，4 天一轮
- 农历显示（内置 1900–2100 农历库，纯 JS 无依赖）
- **精确倒计时**：距开市（08:00）/ 散场（18:00）还剩几分几秒，时间全部按 **北京时间** 计算
- 未来 7 天预览 + 任意日期查询
- **一键导出 .ics**，导入手机日历，赶集前一天下午自动提醒（一次性导出未来 10 年，防重复标记）

### 🎮 怀旧游戏库 · `/game/`
自己写的经典小游戏合集，23 款，触屏 / 键盘双支持。

- **棋牌对弈**：斗地主、保山幺子分、五子棋、井字棋
- **益智解谜**：推箱子、华容道、连连看、2048、拼图、扫雷
- **街机射击**：飞机大战、坦克大战、打砖块、现代小鸟
- **动作冒险**：超级马里奥、大力水手、大鱼吃小鱼、青蛙过河
- **休闲竞速**：极速变道、暴力摩托、乒乓球对战、贪吃蛇、俄罗斯方块

游戏本体存放在 `game/games/` 目录下，主页只做菜单和 iframe 加载。

### ⏰ 工时记账本 · `/gongshi/`
打工人的记账小助手。

- **双模式**：正式工（底薪 + 加班费）/ 临时工（时薪 × 时长）
- 按天记：上班 / 休息 / 请假 / 调休
- 自动算：平时加班 ×1.5、周末 ×2、节假日 ×3
- 支持补贴项（每月一次性 / 每天一次）
- 数据默认存本地，配置 GitHub Token 后可云端同步，多设备通用

## 🛠 技术栈

```
HTML5      — 语义化结构，无障碍优先
CSS3       — 变量、Grid、Flex、backdrop-filter、prefers-* 媒体查询
JavaScript — ES2015+，无框架、无构建、无第三方库
LocalStorage — 本地数据持久化
GitHub API — 可选云端同步（资源导航 / 工时记账）
ICS        — 标准日历文件导出
PWA        — 通过动态 manifest 支持「添加到主屏幕」
```

**零依赖** 是刻意的选择：改一行刷新就能看到效果，没有 node_modules，没有 npm install，也没有构建产物。

## 🚀 本地运行

因为全部是静态文件，**双击 `index.html` 就能打开**。但涉及 `fetch('./data.json')` 的功能（资源导航）需要 HTTP 服务：

```bash
# 方式一：Python（系统自带）
python3 -m http.server 8080

# 方式二：Node.js
npx serve .

# 方式三：任意静态服务器
# 然后浏览器打开 http://localhost:8080/
```

4. 等待 1-2 分钟即可访问

## 🎨 设计原则

- **克制的动效**：只在能帮上忙的地方动（呼吸灯、打字光标、状态信号），并完整支持 `prefers-reduced-motion`
- **顺手的暗色模式**：跟随系统 `prefers-color-scheme`，无需手动切换
- **看得清的字**：明确的三级文字层级（标题 / 正文 / 辅助），浅色深色都保证对比度
- **轻到可以忽略**：单个页面通常 < 100 KB，打开几乎无白屏
- **离线也能用**：除云端同步外，所有功能无需网络
